# Vision project workflow

Train image classifiers with fixed seeds and report macro F1, per-class recall, confusion matrix, and a sample of errors. Use a train/validation/test split. Fit any normalization statistics on training data only. Compare training/validation curves and record compute, epochs, and data version.

The included CIFAR-10 scripts are small, runnable demonstrations of the Keras and PyTorch mechanics. They do not reproduce or claim the geospatial capstone results. Install the framework for the script you choose.
