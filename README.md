# IBM AI Engineering: Retrospective Project Portfolio

Independent portfolio artifacts mapped to the publicly listed IBM AI Engineering Professional Certificate courses. Created retrospectively after certification; these are not recovered, submitted, or graded Coursera assignments. No course-only starter code, solutions, or private lab content is included.

## Projects

- [`projects/ml-baselines/`](projects/ml-baselines/): supervised classification and evaluation using scikit-learn.
- [`projects/vision/`](projects/vision/): comparable CNN training workflows in PyTorch and TensorFlow/Keras.
- [`projects/capstone-geospatial/`](projects/capstone-geospatial/): end-to-end land-cover image classification plan, data contract, augmentation, validation, and metrics.

See [`CURRICULUM_MAP.md`](CURRICULUM_MAP.md). Install optional dependencies for each project separately. Generated metrics and checkpoints are local outputs, not committed results.
